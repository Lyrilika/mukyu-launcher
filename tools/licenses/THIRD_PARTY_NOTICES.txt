Dependency sources
==================
Matching dependency sources and distribution build patches are committed under
third_party/sources, indexed by third_party/manifest.json:
https://github.com/Lyrilika/mukyu-launcher/tree/main/third_party

Use the same Git tag as the downloaded application. GitHub's automatic source
ZIP and tar.gz include this directory. The AppImage and Windows installer do
not contain these dependency source archives, and no separate source release
assets are needed. The builders verify the source checksums and use the pinned
runtime packages identified by the manifest. Original licenses remain inside
the source archives and the packaged distributions' license directories.

The repository snapshot covers the versions recorded in its manifest; older
builds with different dependency versions need their own corresponding sources.
