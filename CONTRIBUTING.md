## Pull request format

Copy the format below into your pull request description. Check the items that apply. AI-assisted contributions are welcome as long as they are disclosed

```markdown
### What

<!-- Describe what changed and why. -->

### Tested

<!-- List what you tested and on which platform (Linux or Windows). Include other relevant information
For packaging changes, say whether you tried the AppImage or Windows installer.
Mention anything you could not test. -->

### Checklist

- [ ] I started from `main` and confirmed this PR covers work outside the scope of every other open PR.
- [ ] This pull request covers one topic.
- [ ] For new dependencies or bundled assets, I noted the source and license.
- [ ] Related issue: <!-- Write Fixes #123 if this closes an issue. Otherwise link it or write None. -->
- [ ] Depends on: <!-- List any prerequisite pull requests, or write None. -->
- [ ] AI-assisted
```
